딜 엔진부패(Decompose)는 시신걸음을 신은 캐릭터가 한 걸음 뗄 때마다 자동 시전되는 스킬이다. 주변 시체를 소비해 서서히 퍼지는 독 구름을 만들고, 구름은 유사 명중(pseudo-hit) 카오스 피해로 중독을 건다. 실제 피해는 중독 부분만이고, 구름 1개는 2초마다 중독 1회를 건다. 피해량은 죽기 전 그 몹의 생명력에 비례 — 레벨과 맵 티어가 올라가면 기본 피해가 저절로 커진다.mobalytics · 개요영상 1:40~2:15
연료 문제와 해법시체가 늘 있는 건 아니다. 희생(Sacrifice)이 내 언데드 소환수를 시체로 취급하게 해준다 → 무언가를 죽이지 않아도 독 구름을 깐다. 그래서 소환수의 생명력이 곧 부패의 기본 피해다. 소환수 딜은 전혀 신경 쓰지 않고 오직 HP만 올린다.mobalytics · 개요영상 2:18~2:41 · 12:27~12:50

용어뜻
방구쟁이 / Fartfinder빌드 이름. Fart(방귀) + Pathfinder의 합성어로 제작자 본인이 붙였다. 걸을 때마다 독가스가 깔리는 그림에서 온 별명이고, 가이드 본문 전체가 방귀 농담으로 쓰여 있다.
시신걸음 / Corpsewade철제 각반 유니크 장화. 부패 스킬을 부여한다 = 빌드의 존재 이유. 착용 제한 11레벨. 완벽한 쥬얼러 오브로 5소켓을 만들어 부패에 보조 5개를 꽂는다.
부패 / Decompose한 걸음마다 자동 시전되어 주변 시체를 먹고 독 구름을 만드는 스킬. 유사 명중 카오스로 중독을 걸며 죽기 전 몹 생명력에 비례해 피해가 정해진다. 젬 레벨은 구름 성능에 영향이 없다.
독성 운반자 / Plague Bearer입힌 중독 총량을 저장했다가 주변에 터뜨리는 스킬. 매핑의 주력이고 세트 1에서만 충전된다.
망령 속박 / Bind Spectre특정 적을 망령으로 포획해 소환하는 스킬. 이 빌드는 피의 정령(Blood Elemental)을 쓴다 — 언데드 망령 중 기본 HP 최고. 세트별 소환 수를 따로 지정해야 하며 세트 2 = 5, 세트 1 = 0.
희생 / Sacrifice부패가 내 언데드 소환수도 시체로 취급하게 만드는 스킬. 58레벨 젬이라 이 빌드의 시작 하한선을 결정한다.

정신력 / Spirit지속형 스킬 예약치. 무기 세트별로 따로 계산되기 때문에 스왑이 실질 정신력을 2배로 만든다. 목표 = 세트1 413 / 세트2 444.

무기 스왑 / 세트 1·2두 벌의 무기 구성을 전환하는 시스템. 세트 1 = 저주·오라·클리어, 세트 2 = 소환수 연료. 스킬은 둘 중 하나에만 켜 둔다(양쪽 필요한 건 부패·해골 저격수·희생).
