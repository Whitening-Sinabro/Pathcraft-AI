## 1. 사용자의 목적·현재 대화 상황

- POE2 0.5.5 Forbidden Rites의 Skadoosh 하코 Warbringer 경로를 다시 진행하려고 한다. 초반에 자주 죽어 준비물과 실제 방송 운영을 상세히 확인해 달라고 했다.
- 사용자 캐릭터 이름은 **HCFB_CCTBurger**다. “아이디”라고 제시한 이름을 별도의 계정명으로 추정하지 않는다.
- 이전 공개 23레벨 상태를 확인한 자료는 있지만, 이 기록 시점의 실제 레벨·장비·패시브·보조 젬 재고는 새로 읽지 않았다. 예전 23레벨을 현재 상태라고 단정하지 않는다.
- 가장 최근에는 **2차 전직 후 04 타락 함성 전환**, “3레벨 보조 젬이 두 개 정도뿐”이라는 제약, 뼈 박살을 포함한 실제 버튼 사용 순서를 물었다. 재고 설명은 **미가공 보조 젬 3레벨 두 개라는 해석**으로 답했다. 인벤토리 실측은 아니다.
- “회복이 부족한 초반에는 빠르게 때리고 처치하는 편이 낫다”는 방향을 요구했다. 생존 수치만 강조하며 주력 피해·타격 속도를 뒤로 미루지 않는다.
- 생명력 +100은 초반에 큰 증가라고 지적했고, 조사 결과를 실제 플래너에서도 볼 수 있어야 한다고 여러 번 요청했다.
- 무기 세트 I·II, 처음 배우는 순간과 이후 완성 연결, 기존 젬의 이동과 빈 소켓, 스킬을 빼는 정확한 단계까지 포함해야 한다.

## 5. 최근 질문: 2차 전직 후 04 전환과 보조 젬 두 개

**준비됐으면 2차 전직 후 04로 전환한다.** 제작자는 Day 2 약 02:56에 2차 전직을 하고, 04:23~04:33 사이에 46레벨 타락 함성 전환·사냥을 진행했다. 전직 완료 즉시 모든 젬·장비가 자동 준비되는 것은 아니다.

처음에는 **보강하는 함성 + 타락시키는 비명 I + 포악함 II + 고통 격화 II**로 시작한다. 충격파 토템과 마나 플라스크를 유지한다. 혈마법·선대의 전사 토템은 이후 05 전환이다.

따라서 사용자가 말한 3레벨 두 개는 **타락 I·고통 격화 II에 각각 하나씩** 쓴다. 2레벨 여분으로 함성용 포악함 II를 준비하며, 기존 토템의 포악함 II는 유지한다. 이 판단은 미가공 젬 재고에 대한 사용자 설명을 전제로 한 안내이며 다른 재료·소켓·능력치가 모두 준비됐다는 확인은 아니다.

등급은 웹 툴팁과 로컬 `SkillGems.json`의 `CraftingLevel`에서 **3 / 3 / 2 / 4**로 대조했다. 보조 이름 뒤의 로마 숫자와 필요한 미가공 젬 레벨을 혼동하지 않는다.

방송에서는 토템의 포악함 II를 함성으로 옮겼다가 **04:24:44~46에 토템에 별도 포악함 II를 다시 넣었다.** 네 번째 보조는 **04:31:00에 효율 I**, 이후 공개 기록에서는 효율 II다. II를 처음 끼운 정확한 초는 아직 미확정이다. [04 연결·빈 소켓 대조](../deliverables/skadoosh_early_survival_2026-09-08/later_planner_audit/후속_플래너_정밀확인.html).

## 6. 최근 질문: 04에서 실제로 누르는 로테이션 전체

**보강하는 함성(I)을 쓰며 이동하는 것이 기본이고, 토템과 나머지 스킬은 상황에 따라 추가한다.** 타락시키는 비명은 보강 안의 보조라서 별도로 누르는 버튼이 없다. 현재 04에는 메아리가 없으므로 06의 10m 이동 제한을 적용하지 않는다.

| 상황 | 실제 버튼 흐름 |
| --- | --- |

## 12. 아직 미확정인 것과 다음 확인 방법

**“다 기록했다”와 “조사를 전부 확정했다”를 구분한다.** 핵심 05·06 배정·연결·무기 세트 안내는 반영했지만 다음 사항은 남아 있다.

| 미확정 항목 | 다음 확인 방법 | 완료 판단 기준 |
| --- | --- | --- |
| 메아리 회복량·비용 상쇄량 | 피격·처치·플라스크가 섞이지 않는 조건에서 기본 재생을 먼저 측정하고 함성 1회·각 메아리 직후 체력 변화를 대조. 동시에 비용·회복이 발생하면 회복 효과 유무도 비교 | 같은 조건에서 분리할 수 있는 수치·영상. 방송 체력 움직임만으로 확정하지 않음 |
| 보조 젬 최초 장착 초 | 마지막 미장착 화면과 첫 장착 화면 사이를 좁히고 젬 창 주변을 0.5~1초 간격으로 대조 | 제작·툴팁·실제 소켓 장착을 구분한 장면 |
| 수정된 05·06의 게임 표시 | 게임에서 플래너를 다시 선택해 패시브·무기 특화·젬 목록을 파일과 비교하고 오류 로그 확인 | 수정 파일에 대한 새 로드 증거. 과거 02 화면·로드 로그로 대체하지 않음 |
| 필터 v4 게임 적용 | 선택 중인 필터를 새로고침한 뒤 해당 버전 로드와 실제 표시 확인 | 최신 파일 적용 증거 |

보조 최초 시각의 구체적인 잔여 범위는 우주의 영사·효율 I, 활력 등급별 첫 장착과 세트 매핑 시점이다. 더 넓은 이전 조사에서는 04 효율 I→II, 03 전쟁의 주먹 II·활력 I, 07 토템 상위 보조의 최초 순간도 모두 확정하지 않았다. 연결 목표를 아는 것과 최초 장착 시간을 아는 것은 별개다.

현재 사용자 캐릭터의 정확한 장비·패시브, 통제된 실전 총 DPS·다수 피격 생존도 검증한 것으로 표시하지 않는다. 최근 대화에서 즉시 진행하기로 확정한 추가 실험은 없으며, 이번 지시는 저장 후 종료다.

## 13. 저장 후 컴퓨터 종료 요청

사용자가 **모두 저장한 뒤 컴퓨터를 끄라**고 명시했다. 문서 저장·링크·파일 보존 검사를 마친 뒤 Windows 종료를 요청한다. 종료 요청의 준비·실행 상태는 [기록 검증 파일](../deliverables/skadoosh_early_survival_2026-09-08/conversation_checkpoint_validation.json)에 남긴다. 운영체제가 실제 전원 종료까지 완료됐다는 사실은 종료 전에 작성하는 이 문서에서 확정하지 않는다.

다음 세션에서는 이 기록과 최신 05·06 복원 자료부터 읽고, 이미 확인한 구간 전체를 처음부터 다시 조사하지 않는다. 사용자에게 현재 레벨·재고를 말할 때는 이 기록의 과거 관찰과 새로 확인한 현재 상태를 구분한다.
