5. 최근 질문: 2차 전직 후 04 전환과 보조 젬 두 개

준비됐으면 2차 전직 후 04로 전환한다. 제작자는 Day 2 약 02:56에 2차 전직을 하고, 04:23~04:33 사이에 46레벨 타락 함성 전환·사냥을 진행했다. 전직 완료 즉시 모든 젬·장비가 자동 준비되는 것은 아니다.

처음에는 보강하는 함성 + 타락시키는 비명 I + 포악함 II + 고통 격화 II로 시작한다. 충격파 토템과 마나 플라스크를 유지한다. 혈마법·선대의 전사 토템은 이후 05 전환이다.

제작할 보조 필요한 미가공 보조 젬 사용처·재고 판단
타락시키는 비명 I 3레벨 1개 보강하는 함성
고통 격화 II 3레벨 1개 보강하는 함성
포악함 II 2레벨 1개 새 함성용. 토템용까지 합치면 총 2개 필요
효율 II 4레벨 1개 네 번째 보조의 성장 목표. 처음부터 필수로 요구하지 않음

따라서 사용자가 말한 3레벨 두 개는 타락 I·고통 격화 II에 각각 하나씩 쓴다. 2레벨 여분으로 함성용 포악함 II를 준비하며, 기존 토템의 포악함 II는 유지한다. 이 판단은 미가공 젬 재고에 대한 사용자 설명을 전제로 한 안내이며 다른 재료·소켓·능력치가 모두 준비됐다는 확인은 아니다.

등급은 웹 툴팁과 로컬 SkillGems.json의 CraftingLevel에서 3 / 3 / 2 / 4로 대조했다. 보조 이름 뒤의 로마 숫자와 필요한 미가공 젬 레벨을 혼동하지 않는다.

방송에서는 토템의 포악함 II를 함성으로 옮겼다가 04:24:44~46에 토템에 별도 포악함 II를 다시 넣었다. 네 번째 보조는 04:31:00에 효율 I, 이후 공개 기록에서는 효율 II다. II를 처음 끼운 정확한 초는 아직 미확정이다. 04 연결·빈 소켓 대조.

6. 최근 질문: 04에서 실제로 누르는 로테이션 전체

보강하는 함성(I)을 쓰며 이동하는 것이 기본이고, 토템과 나머지 스킬은 상황에 따라 추가한다. 타락시키는 비명은 보강 안의 보조라서 별도로 누르는 버튼이 없다. 현재 04에는 메아리가 없으므로 06의 10m 이동 제한을 적용하지 않는다.

상황 실제 버튼 흐름
일반 무리 보강 → 이동 → 남은 적에게 보강. 도중에 기절 준비 표시가 뜨면 뼈 박살 → 이동
밀집 무리·희귀 충격파 토템 II → 보강 I → 이동하며 보강 반복. 적이 한곳에 머물고 틈이 있으면 지진의 요철 지대를 보탬
보스 토템 설치 → 보강 → 패턴 회피를 기본으로 유지. 공격할 틈에 지진, 망치까지 쓸 여유가 있으면 망치 → 망치 근처에서 보강
토템 보충 사망·만료·적이 공격 범위를 벗어났을 때 필요한 만큼 다시 설치

수정된 05·06의 게임 표시 게임에서 플래너를 다시 선택해 패시브·무기 특화·젬 목록을 파일과 비교하고 오류 로그 확인 수정 파일에 대한 새 로드 증거. 과거 02 화면·로드 로그로 대체하지 않음
필터 v4 게임 적용 선택 중인 필터를 새로고침한 뒤 해당 버전 로드와 실제 표시 확인 최신 파일 적용 증거

보조 최초 시각의 구체적인 잔여 범위는 우주의 영사·효율 I, 활력 등급별 첫 장착과 세트 매핑 시점이다. 더 넓은 이전 조사에서는 04 효율 I→II, 03 전쟁의 주먹 II·활력 I, 07 토템 상위 보조의 최초 순간도 모두 확정하지 않았다. 연결 목표를 아는 것과 최초 장착 시간을 아는 것은 별개다.

현재 사용자 캐릭터의 정확한 장비·패시브, 통제된 실전 총 DPS·다수 피격 생존도 검증한 것으로 표시하지 않는다. 최근 대화에서 즉시 진행하기로 확정한 추가 실험은 없으며, 이번 지시는 저장 후 종료다.

13. 저장 후 컴퓨터 종료 요청

사용자가 모두 저장한 뒤 컴퓨터를 끄라고 명시했다. 문서 저장·링크·파일 보존 검사를 마친 뒤 Windows 종료를 요청한다. 종료 요청의 준비·실행 상태는 기록 검증 파일에 남긴다. 운영체제가 실제 전원 종료까지 완료됐다는 사실은 종료 전에 작성하는 이 문서에서 확정하지 않는다.

다음 세션에서는 이 기록과 최신 05·06 복원 자료부터 읽고, 이미 확인한 구간 전체를 처음부터 다시 조사하지 않는다. 사용자에게 현재 레벨·재고를 말할 때는 이 기록의 과거 관찰과 새로 확인한 현재 상태를 구분한다.
