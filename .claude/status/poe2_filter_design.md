### T0 자리는 비운다 (HARD)

NeverSink `apex_stier` 와 Crimson T0 가 **둘 다 "흰 배경 + 빨간 글자 45 + 크기0 별"** 이다.
NeverSink 는 이 옷을 미러·신성 오브·T1 고유 등 **149종**에 입힌다.
우리 최상위는 **반대 배치**(진홍 배경 + 흰 글자)여야 미러급 경보와 안 겹친다.

보라를 쓰면 안 되는 이유도 같다 — NeverSink 에서 보라는 고유·조각·시험 열쇠 채널(31블록)이고
`MinimapIcon 0 Purple Star` 는 이중부패/발라 유니크 아이콘과 **정확히 충돌**한다.

## 빌더에 생긴 기능

1. **스타일의 `sound`/`beam`/`icon` 을 `null` 로 끌 수 있다.** 끄더라도 **베이스가 요구하면
   자동으로 켜진다** — 라우드니스 게이트가 그대로 산다.
2. **`PlayEffect <색> Temp`** 지원. 값 게이트가 색만 기록하고 있어서 못 쓰던 것
   (베이스는 52번 쓴다).
3. **GGG 공식 값 목록이 상위 권위**(`OFFICIAL_VALUES`). 베이스 필터는 합법성의
   *대리 지표*지 권위가 아니다 — `Raindrop` 은 공식 목록에 있는데 NeverSink 가 안 쓸 뿐이었다.
   출처: pathofexile.com/item-filter/about (2026-09-04 확인).
   폰트 **1-45**(45가 상한) · 소리 id **1-16** · 음량 **0-300** · 아이콘 크기 **0-2**
   · 색 11종 · 모양 12종.
4. **`kind: "hide"` 룰.** 배치는 Show 뒤·베이스 앞. 숨김 룰의 Class·BaseType 을
   스펙의 모든 Show 룰과 교차해 **하나라도 겹치면 빌드가 죽는다**(기계 게이트).

## 숨김 — NeverSink 것을 각색해 쓴다

NeverSink 는 `conditionalhiders` 14블록을 **다 써놓고 꺼서 배포한다**
(soft L687-L864, 활성 0 / 주석 14). **그대로 켜면 안 된다** — 그쪽 무기 목록에
`"Crossbows"` 와 `"Staves"` 가 들어 있는데 그게 정확히 이 빌드의 무기다.
게이트 시험에서 실제로 종료코드 1 로 죽는 것을 확인했다.

우리 숨김 룰(못 쓰는 무기·보조장비 12클래스)이 쓰는 안전장치는 NeverSink 것 그대로:

    Rarity Normal Magic         레어·유니크는 목록에 없어 절대 안 숨는다
    Sockets 0                   룬 슬롯 뚫린 것 남음
    Quality 0                   퀄리티 붙은 것 남음
    UnidentifiedItemTier <= 3   상위 티어 미감정 남음
    AreaLevel >= 12             무기를 고를 여지가 있는 초반은 안 건드림

`UnidentifiedItemTier` 가 노말·매직에 실제로 걸리는지 확인함 — NeverSink **활성 블록
13개**가 `Rarity Normal Magic` + `UnidentifiedItemTier <= 2` 를 쓴다.

## 밟은 지뢰

- **B급 폰트를 40 으로 두면 회귀 291건.** NeverSink 의 레벨링 레어 장비 티어가
  폰트 42 인데(soft L4729 `leveling->rare->universal $tier->jewellery`) 그 블록은
  `AreaLevel` 조건이 있어 라우드니스 게이트의 비교 대상에서 빠진다. **42 로 맞춰야 한다.**
- **변이 블록의 바닥은 스타일이 아니라 일반 블록이 확보한 값**이다. 스타일 값으로 두면
  베이스 때문에 올려둔 상향분이 통째로 사라진다(진주광 목걸이 회귀 72건).
- **`poe2_filter_eval.py` 는 `UnidentifiedItemTier` 를 모델링하지 않는다.**
  그래서 숨김 효과는 시뮬레이션으로 못 본다 — 인게임 확인이 필요하다.
- **heredoc 이 백슬래시를 먹는다.** `\n` 이 실제 개행이 되어 문자열이 안 닫힌다.
  이번 세션에서 또 밟았다. 이스케이프가 들어가는 편집은 Write/Edit 로.

## 게임 폴더 관찰

- `Config.ini` 의 **`item_filter_loaded_successfully=<파일명>`** 이 게임이 직접
  "로드 성공"을 기록한 자리다. 필터가 실제로 먹었는지는 여기서 확인한다.
- 필터 위치는 **루트**(`My Games/Path of Exile 2/`)가 맞다. `CustomFilter/` 안의 것은
  남의 도구가 남긴 것.
- **설치한 `.filter` 와 `.build` 가 사라진다.** 게임이 읽고 자기 저장소로 가져가는 것으로
  보이지만 확증은 없다. 목록에 남아 있으면 정상.
