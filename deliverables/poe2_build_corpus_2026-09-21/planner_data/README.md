# 플래너 공통 근거 데이터

`build_data.json`과 같은 내용의 `build_data.js`를 `../build_planner_data.py`로 생성한다. 제품 코드는 실행하거나 변경하지 않는다.

- `stages`: 탱정 28509/285e2/28604/28695/29d39의 실제 선택 SkillSet·ItemSet·Tree. 앞의 네 개는 과거 비교 자료이며 최신으로 가는 필수 경로가 아니다.
- `campaign_stages`: 기존 영상·업데이트·카페 검토에서 확인된 스킬 및 장비 유형을 Pathcraft가 정리한 육성 참고안. 탱정의 실제 액트별 세팅 복원이 아니다. 일반 패시브 18/26/37/47/56포인트를 Pathcraft 체크포인트로 구성했으며 다른 전직 노드는 넣지 않는다. campaign_checkpoint는 정확한 ID·조건·추가/환불 경로와 근거를 보존한다.
- `reference_trees`·`reference_skill_sets`: 별이슬골짜기의 원본 자료. 원래 제목·전직을 유지하며 Kitava의 기본 계획으로 자동 복사하지 않는다.
- `tree`: 기존 `tree_0_5.json`의 노드 이름·효과·실제 연결·좌표. 노드가 포함된 group을 직접 대응하고 원본 orbit angle을 사용한다. 스냅샷에 할당된 집합과 직접 이웃만 포함한다. 캠페인 후보의 연결성 및 추가/환불 증거는 별도 Pathcraft 구성으로 검증하며 원저자의 클릭 순서로 주장하지 않는다.

최신 151개 노드는 공통104/무기세트1 24/무기세트2 23으로 분리된다. 클래스·전직 시작 노드도 원본 집합에 포함한다. 장비와 주얼에 의한 동적 효과를 재계산하지 않으며 XML Sockets/Overrides를 별도 보존한다. `source_type`이 Tree/Item/Thorns인 그룹은 부여 스킬 또는 계산용 그룹이므로 구매 젬 추천으로 중복 표기하지 않는다.

스냅샷 캐릭터·젬 레벨은 최소 전환 기준이 아니다. 캠페인에는 고레벨 스냅샷의 젬 레벨·품질을 옮기지 않았다. 장비 옵션의 `{range:...}` 및 수치 범위는 원문 표기이며 실제 확정 롤로 해석하지 않는다. 기존 배포10개의 게임 로그 로드, 사용자 B스킬/A2패시브 표시 성공 및 수정 전 액트3 스킬 추천 직접 관측을 구분해 기록했다. 새 캠페인 경로의 전투·하드코어 안전 검증은 수행하지 않았다. 파일별 SHA-256과 구조 확인 결과는 `validation.json`에 있다.
