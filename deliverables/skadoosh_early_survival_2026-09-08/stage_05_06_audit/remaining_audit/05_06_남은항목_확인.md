# Skadoosh 05·06 — 미완료 항목 추가 확인

**54·65레벨 패시브와 지진 함성 첫 장착 시점을 추가 확인했다.** 05·06 플래너는 방송 화면에서 복원한 배정으로 교체했다. 이전의 두 단계 공통 69점 전환안과 그 회복·방어 80점 확장 설명은 현재 목표에서 제외한다.

조사 대상은 [셋째 방송 2866749730](https://www.twitch.tv/videos/2866749730)이다. 음성 인식에서 설명 구간을 찾고 해당 구간의 스킬 창·패시브 이동 화면을 확대했다. 전체 방송을 처음부터 끝까지 연속 시청한 결과는 아니다. 공개 API의 제공 시점에는 정확한 54·65레벨 저장본이 없어 **방송 화면의 선택 경로·무기 세트 색·남은 포인트를 대조한 복원본**으로 구분했다.

## 1. 05 — 54레벨 패시브 복원

| 항목 | 화면과 대조한 결과 |
| --- | --- |
| 일반 포인트 사용 | **71점 = 공통 57 + 특화 14** |
| 무기 특화 | **I 14 / II 14**. 각 18점 한도 중 4점 남음 |
| 전직 | 4점 |
| 일반 남은 포인트 | 0점 |
| 보존한 회복·토템 가지 | Hard to Kill, Ancestral Mending, Spirit Bond, Ancestral Conduits |
| I 특화 | Cacophony 4점, Urgent Call 4점, Guttural Roar 2점, **Lay Siege 4점** |
| II 특화 | Watchtowers 4점, Ancestral Artifice·Unity 4점, Spirit Bond·Ancestral Conduits 6점 |

각 특화는 해당 주요 노드까지의 작은 노드를 포함한 점수다. 일반 사용량에 I와 II를 두 번 더하지 않는다.

처음 만든 후보에서는 **Bolstering Yell 가지 4점을 잘못 남기고 Lay Siege 가지 4점을 뺐다.** 두 가지 모두 4점이라 총점 검사만으로는 이 오류가 드러나지 않았다. 54레벨 화면에서 I의 방패 가지가 선택되어 있고 Bolstering Yell은 비어 있는 것을 확대 대조해 바로잡았다. 그 후보는 설치하지 않았으며 이번 플래너에는 수정한 배정을 넣었다.

**54레벨에 Carved Earth는 환불된 상태**다. 00:28:46~48의 환불 이후 화면과 대조했다. Roaring Cries와 Howling Beast도 아직 없다. 00:29:54에 찍은 물리 피해 작은 노드 2개는 반영하되, 이후 툴팁만 띄운 Cruel Methods 주요 노드는 이 단계에 넣지 않았다.

## 2. 06 — 65레벨 패시브 복원

| 항목 | 화면과 대조한 결과 |
| --- | --- |
| 일반 포인트 사용 | **87점 = 공통 65 + 특화 22** |
| 무기 특화 | **I 22 / II 22**. 각 24점 한도 중 2점 남음 |
| 전직 | 4점 |
| 일반 남은 포인트 | 1점: 총 88점 중 87점 사용 |

**05와 같은 트리가 아니다.** 54레벨의 배정과 세트 구분을 모두 유지한 채 아래 가지를 추가한 상태다. 표는 두 시점 사이의 차이이며, 이 순서대로 레벨마다 눌렀다는 뜻은 아니다.

| 구분 | 54→65 추가 배정 | 실제 추가 노드 |
| --- | --- | --- |
| 공통 | Tempered Defences 가지 4, Battle-hardened 쪽 2, 치명타 경로 작은 노드 1, Cruel Methods 1 | 8 |
| I | Roaring Cries 가지 3, Howling Beast 가지 3, Defender’s Resolve 가지 2 | 8 |
| II | Carved Earth 가지 4, Bonded Precision 가지 3, 토템 작은 노드 1 | 8 |

총 24개 노드가 늘지만 I·II 특화는 대응하는 포인트를 사용하므로 **일반 사용량 증가는 16점**이다. 05→06은 환불이나 세트 재배정 없이 연결된다.

**Desensitisation과 Battle Fever는 65레벨에 넣지 않았다.** 05:03:08의 Desensitisation 설명은 툴팁을 띄운 장면이며 배정 완료 증거가 아니다. 74레벨 보존본에서 65레벨로 역산할 때는 두 가지와 추가 경로·주얼 슬롯, 후기 전직 2점을 제외하고 화면 전체 경로를 다시 대조했다.

## 3. 지진 함성 첫 장착 — 00:52:21~23

**05 단계에서 이미 배운다.** 00:52:00에는 전사 토템과 공명하는 방패 사이의 스킬 칸이 비어 있다. 이후 장면을 1초 간격으로 다시 확인했다.

| 방송 시각 | 확인한 동작 |
| --- | --- |
| 00:52:09~19 | 여러 등급의 미가공 스킬 젬을 살펴본 뒤 11레벨 젬으로 돌아옴 |
| **00:52:21~22** | **11레벨 Seismic Cry 생성 및 인벤토리 툴팁 확인** |
| **00:52:23** | **빈 스킬 칸에 지진 함성 장착** |
| 00:52:28~31 | 단축키 선택 목록에도 지진 함성이 나타남 |

앞선 5초 간격 탐색에서는 00:52:20의 다른 스킬 툴팁 뒤에 이어지는 1~3초 동작을 놓쳤다. 따라서 “최초 추가 시점 미확정”을 위 시점으로 정정했다. **우주의 영사·효율 I까지 연결한 시점과 젬 자체를 처음 장착한 시점은 다르다.** 두 보조가 연결된 모습은 기존에 확인한 02:35:41 이전에는 완성돼 있다. 보조 각각의 최초 장착 초는 이번에 확정하지 않았다.

## 4. 플래너에 반영한 범위와 검사

05·06의 패시브, 해당 단계 설명, 지진 함성 첫 장착 안내를 수정했다. 기존에 정정한 젬 연결은 유지한다. 현재 배포 ZIP에도 같은 파일을 넣었다.

## 5. 아직 확정하지 못한 부분

- **메아리 1회당 실제 회복량과 비용 상쇄량.** 04:59:33에 메아리도 회복시킨다는 설명은 있지만 재생·처치 회복·피격·플라스크가 섞인다. 이번 방송만으로 분리한 숫자는 제시하지 않는다. 앞서 만든 [해당 설명 재생 자료](../05_06_설명장면_재확인.html)는 유지한다.
- **우주의 영사·효율 I, 두 불의 순수함의 활력 등급별 최초 장착 시각.** 지진 함성 자체의 첫 장착은 해결했다. 보조 연결의 최초 시각은 별개로 남겨 둔다. 03:35:28~03:36:03을 다시 봤지만 상당 부분이 젬 메뉴 탐색·툴팁으로, 활력 I/II를 어느 항목에 처음 넣었는지 확정할 장면은 아니었다. 기존 연결은 보존본 근거를 유지한다.
- **게임에서 수정된 두 플래너를 다시 선택했을 때의 표시.** 파일 형식·노드 연결·포인트·설치본과 ZIP의 동일성 검사를 통과했다. 이번 수정 뒤 게임 내부 재불러오기는 확인하지 않았다. 실제 캐릭터의 패시브나 G의 세트 체크를 자동 변경한 것은 아니다.
