## 작업자 산출물과 검증 기준

작업자는 **worker/** 아래에만 기록한다. 기존 HANDOFF와 sources는 수정하지 않는다. 조정자는 별도 MERGED_RESEARCH.md에 통합한다.

1. `worker/REVIEW.md`: 한국어 독립 검증 결과, 기존 주장별 확인/정정/미확인, 구체적인 장비·스킬·전직 전환 및 실제 조작 증거.
2. `worker/coverage.json`: 영상별 실제 검증한 시작/끝 초, 방법(자막/연속 재생 관찰/프레임 샘플/화면 변화 탐지/원본 상태 비교), 증거 파일, 미확인 구간. **고정 간격 캡처나 자막만으로 연속 시청 완료 표시 금지.**
3. `worker/events.jsonl`: 중요한 화면 변화의 영상 ID/시각/전후 상태/확인 방법/증거 경로. 말없이 젬을 바꾼 순간도 포착 대상으로 삼는다.
4. 전체 타임라인을 확인할 방법을 먼저 실제 짧은 연속 구간에서 검증한다. 임의 10초 건너뛰기는 사용하지 않는다. 자동 감지·촘촘한 프레임은 후보 탐지 수단이며 연속 시청과 동등하다고 하지 않는다. 빠른 클릭·보조 젬/무기 변경 구간은 앞뒤를 포함해 다시 관찰한다.
5. 3일차 2부 자막 생성 여부를 재확인한다. 필요하고 가능한 경우 기존 로컬 ASR/영상 도구를 조사 전용 파일에 재사용하되, 도구를 돌린 사실과 사람이 확인 가능한 영상 내용의 검증을 구분한다. 앱 설치나 유료 서비스 구입은 이 과업에 포함되지 않는다.
6. 완료 조건을 충족하지 못하면 미검증 범위와 구체적 도구 한계를 그대로 보고한다. 일부만 확인하고 전체 영상 검증 완료를 선언하지 않는다. 접근 가능한 작업은 계속 진행한다.
7. 다른 세션·게임·설정·필터·플래너·Google Docs 수정, Git 커밋/브랜치 병합/푸시, 외부 게시/메시지, 임의 프로세스 종료 금지.

## 브라우저와 자막 UI 주의

현재 조정자의 Node REPL에 실제 Playwright MCP 서버와 기존 외부 브라우저 연결이 살아 있다. 별도 브라우저를 띄우지 않도록 조정자가 제공하는 전용 로컬 브리지 지침을 따른다. 기존 사용자 Docs/YouTube/PoB/Mobalytics 탭은 건드리지 않는다. 탭 순서는 변할 수 있으므로 URL로 확인한다.

YouTube 스크립트 UI는 `transcript-segment-view-model`을 사용한다. 구형 `ytd-transcript-segment-renderer`는 0개다. 메타데이터 설명의 더보기 후 `스크립트 표시` 버튼을 누르고, `.ytwTranscriptSegmentViewModelTimestamp`와 `span[role=text]`에서 추출했다. 페이지 초기 hydration으로 UI가 다시 접힐 수 있다. 자막 direct URL은 200 빈 응답이었던 적이 있으므로 빈 응답을 자막 없음으로 단정하지 않는다.

현재 브라우저에는 미디어 자동 음소거/일시정지 init script가 있을 수 있다. 재생 확인 시 currentTime이 실제 증가하는지 두 관찰로 확인한다. 필요하면 작업자 전용 새 탭 하나만 같은 브라우저에 만들고, 다른 사용자의 탭은 닫지 않는다. 지속 재생만 해두고 프레임을 보지 않은 시간을 관찰 완료로 표시하지 않는다.
