2026-09-08 사용자 최종 정정: "라이브, 유튜브 영상 두개다 해야지"

정확한 목표는 탱정-탱커의 정석의 **일반 업로드 키타바 자료 영상 4편 + POE2 0.5.5 라이브 모두**를 검증하고 비교하는 것이다. 직전의 '라이브는 대상이 아니므로 중단' 해석은 철회한다. 기존 같은 Task/Dispatch/세션에서 계속하며, 수집한 라이브 증거도 유지한다.

먼저 HANDOFF.md와 PLAYWRIGHT_BRIDGE.md를 읽는다. 원자료는 sources/에 있고 다른 세션이 수집한 것이므로 기존 사실을 무비판적으로 검증 완료로 복사하지 않는다.

대상:
- 일반 업로드: https://www.youtube.com/channel/UCSlN0zTczYpNJHCbskGuYaw/videos 에서 사용자가 말한 키타바 자료 4편의 정확한 URL/제목/길이/날짜를 식별한다. 찾은 목록을 조정자에게 현재 Dispatch status로 먼저 보낸다.
- 라이브: ccC6FzUKYxE(2일차), fxyFr-Sde0U(3일차 1부), LPVyK8hzlCQ(3일차 2부). 첫날은 존재하지만 현재 재생 가능한 원본을 확보하지 못했다.
- 버전은 0.5.5. 네 가이드 중 과거 0.5 영상이 있다면 관련 업데이트/적용 근거를 구별한다. 편수 맞추려고 라이브/다른 제작자 자료를 끼워 넣지 않는다.

검증:
1. 기존 실제 Playwright MCP 브리지를 사용한다. 새 브라우저/추가 MCP 서버/추가 작업자를 만들지 않는다. 같은 브라우저의 전용 연구 탭을 사용하고 음소거한다. 사용자 탭과 다른 세션은 조작하지 않는다.
2. 사용자는 10초 건너뛰기 때문에 말없이 바뀌는 장비·보조 젬·무기·패시브와 운영이 누락된다고 지적했다. 영상, 전체 자막, 설명란, 고정 댓글, 직접 연결된 PoB/가이드를 서로 대조한다. 중요한 화면 변경은 앞뒤 맥락을 포함해 촘촘하게 확인한다.
3. 도구가 정적 이미지·텍스트를 반환하는 한계를 숨기지 않는다. 실제 본 화면, 자막, 자동 탐지, 재생 상태 시험, 미확인 구간을 coverage에 구별한다. 정지 프레임이나 재생해 둔 시간만으로 연속 시청/전체 무누락 검증을 주장하지 않는다.
4. 가이드에서 권한 내용과 라이브에서 실제 채용한 내용을 비교한다. 장비 전환 조건, 전직 변경, 젬 연결/교체, 무기와 스킬 사용, 회복 구성, 완성 전의 위험/제약을 근거별로 정리한다. PoB 캐시 DPS/EHP를 실제 성능 검증으로 취급하지 않는다.
5. worker/REVIEW.md, worker/coverage.json, worker/events.jsonl 및 worker/evidence/에 결과를 작성한다. 일반 영상 네 편과 라이브의 커버리지를 각각 표시하고, 미확인 영상/시간/조건은 남긴다. URL+정확한 시각+관찰 방법을 주요 사실에 붙인다.
6. 범위별로 가능한 검증을 계속 진행한다. 도구 한계로 완수하지 못하면 가능한 작업을 마친 후 구체적인 미완수 범위를 정직하게 보고한다. 전체 검증에 성공하지 않았는데 성공한 것처럼 선언하지 않는다.
7. 영상 한 묶음을 처리할 때마다 Orca 현재 Dispatch의 inbox를 확인해 사용자 정정을 반영한다. 조정자 질문에는 현재 Dispatch로 답하고, 완료 시 주입 preamble의 worker_done을 정확히 한 번 사용한다.
