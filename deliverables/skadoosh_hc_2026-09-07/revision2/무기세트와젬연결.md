# 무기·스킬셋과 사용 순서

빌드 설명 맨 앞에 무기 I/II, 해당 스킬과 연결 젬, 사용 순서를 모았다. 무기 칸에도 해당 세트의 전체 연결표와 추천 옵션을 함께 표시한다. 각 스킬·보조의 개별 설명도 유지했다. G의 무기 세트는 직접 지정한다.

## 01 시작-근접 기초

무기·스킬셋
G에서 세트 I 목록은 I만, 세트 II 목록은 II만 체크한다. 아래는 권장 배정이며 자동 설정되지 않는다.

세트 I · 한손 철퇴 + 방어도 방패
몰려오는 강타 → 연결 보조 없음
지옥불 함성 → 연결 보조 없음
방패 들기 → 연결 보조 없음

세트 II · 양손 철퇴
철퇴 타격 [기본 공격] → 연결 보조 없음
뼈 박살 → 충돌 충격파

세트 II를 한손 철퇴+공유 방패로 바꾸려면 토템 피해를 비교한 뒤 대체한다. 양손 철퇴를 쓰는 동안 보조 무기 II는 비운다.

사용 순서
몰려오는 강타(I) → 기절 준비된 적에게 뼈 박살(II) → 방패 I 복귀.

지금 할 일
1. 몰려오는 강타로 기절을 준비하고 뼈 박살로 마무리한다.
2. 미가공 스킬 젬 3레벨을 얻으면 충격파 토템을 제작하고 02를 선택한다.
3. 3레벨 충격파 토템은 캐릭터 6레벨·힘 14부터 사용한다. 패시브 10점 완성이나 액트 1 완료를 기다리지 않는다.

I: 한손 철퇴+방어도 방패 / II: 양손 철퇴 또는 피해를 확인한 한손 철퇴
다음: 충격파 토템 확보 → 02

## 02 초반-토템 도입

무기·스킬셋
G에서 세트 I 목록은 I만, 세트 II 목록은 II만 체크한다. 아래는 권장 배정이며 자동 설정되지 않는다.

세트 I · 한손 철퇴 + 방어도 방패
몰려오는 강타 → 기절 I
지진 → 지속시간 연장 I
지옥불 함성 → 연결 보조 없음
마그마 장벽 [버프] → 연결 보조 없음
방패 들기 → 연결 보조 없음

세트 II · 양손 철퇴
철퇴 타격 [기본 공격] → 연결 보조 없음
뼈 박살 → 충돌 충격파 + 범위 확대 I
충격파 토템 → 과잉 I + 포악함 I

세트 II를 한손 철퇴+공유 방패로 바꾸려면 토템 피해를 비교한 뒤 대체한다. 양손 철퇴를 쓰는 동안 보조 무기 II는 비운다.

사용 순서
충격파 토템(II) 설치 → 지진(I)으로 지대 생성 → 이동. 기절 준비된 적은 뼈 박살(II)로 마무리하고 I로 복귀.

지금 할 일
1. 충격파 토템을 세트 II에 지정하고 적 앞에 설치한다.
2. 과잉 I → 포악함 I 순서로 확보해 토템에 넣는다. 보조가 없어도 토템부터 쓸 수 있다.
3. 기존 근접 스킬을 함께 쓴다. 일반 25점은 앞으로 찍을 트리 목표이며 진입 조건이 아니다.

I: 한손 철퇴+방어도 방패 / II: 양손 철퇴 또는 피해를 확인한 한손 철퇴
다음: 1차 전직과 토템 보조 3칸 → 03
패시브 목표: 일반 25점 / 무기 특화 I 4점·II 4점.

## 03 1차전직-충격파 토템

무기·스킬셋
G에서 세트 I 목록은 I만, 세트 II 목록은 II만 체크한다. 아래는 권장 배정이며 자동 설정되지 않는다.

세트 I · 한손 철퇴 + 방어도 방패
방패 들기 → 연결 보조 없음
공명하는 방패 → 격노 I
화산 균열 → 요철 지대 I
지진 → 잠식하는 지대 + 유지되는 대지 I
몰려오는 강타 → 목전 I
마그마 장벽 [버프] → 연결 보조 없음
지옥불 함성 → 연결 보조 없음

세트 II · 양손 철퇴
충격파 토템 → 빠른 공격 I + 긴급한 토템 I + 포악함 II
뼈 박살 → 충돌 충격파

세트 II를 한손 철퇴+공유 방패로 바꾸려면 토템 피해를 비교한 뒤 대체한다. 양손 철퇴를 쓰는 동안 보조 무기 II는 비운다.

자동 부여 · 별도 젬 제작 불필요
선대의 혼백 → 연결 보조 없음

사용 순서

지금 할 일
1. 1차 전직 응답받은 부름을 얻은 뒤 토템 연결을 바꾼다.
2. 충격파 토템에 빠른 공격 I·긴급한 토템 I·포악함 II를 연결한다.
3. 과잉 제거로 줄어드는 토템 1기는 전직에서 얻는 1기로 상쇄된다. 전직 전에 보조만 먼저 바꾸지 않는다.

## 09 준비완료-AWT와 파콰테

무기·스킬셋
G에서 세트 I 목록은 I만, 세트 II 목록은 II만 체크한다. 아래는 권장 배정이며 자동 설정되지 않는다.

세트 I · 성소 셉터 + 방어도 방패
불의 순수함 [셉터 부여] → 활력 II + 식인 II + 따뜻한 피
방패 들기 → 연결 보조 없음
공명하는 방패 → 격노 I + 방어구 철거자 I
마그마 장벽 [버프] → 연결 보조 없음
보강하는 함성 → 파콰테의 맹약 + 메아리치는 함성 + 포악함 II + 고통 격화 II
지진 함성 → 우주의 영사 + 효율 II + 격노하는 함성

세트 II · 한손 철퇴 + 성소 셉터
불의 순수함 [셉터 부여] → 활력 I + 정밀함 II
선대의 전사 토템 → 지면 분쇄 [토템 내부 공격] + 긴급한 토템 III + 파생하는 균열 I + 포악함 III

자동 부여 · 별도 젬 제작 불필요
선대의 혼백 → 연결 보조 없음
광기의 선구자 → 연결 보조 없음
광기의 선구자는 원본 고유 철퇴를 사용할 때만 부여된다.

사용 순서
선대의 전사 토템(II) 설치 → 보강하는 함성(I)으로 방패 복귀·가시 폭발 → 이동. 지진 함성(I)은 보조.

지금 할 일
1. 참고 단계다. 추가 생명력 비용을 직접 확인하기 전에는 08C를 유지한다.
2. 전환할 때만 타락시키는 비명 I를 파콰테로, 효율 II를 메아리치는 함성으로 교체한다.
3. 메아리는 1.3초 간격으로 2회 반복한다. 다음 직접 사용 전 10미터 이동이 필요하다. 반복 비용이 감당되는지 먼저 확인한다.

I: 성소 셉터+방어도 방패 / II: 한손 철퇴+성소 셉터
다음: 추가 비용을 감당하지 못하면 08C 복귀
패시브 목표: 일반 97점 / 무기 특화 I 22점·II 22점.
